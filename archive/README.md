# Archive

Denne mappen inneholder gamle filer som ikke lenger er i bruk, men som vi ønsker å beholde for historisk referanse.

## Struktur

- `docs/old/` - Gamle dokumenter fra tidligere faser
- `docs/drafts/` - Utkast og eksperimentelle dokumenter
- `migrations/failed/` - Migrasjoner som feilet og ble erstattet
- `scripts/deprecated/` - Gamle scripts før automatisering

**⚠️ Aldri bruk filer herfra i produksjon!**
