# Timeout-guards på 5 kritiske API-ruter

> **For Hermes:** Bruk subagent-driven-development for å implementere planen task-by-task.

**Mål:** Legg til AbortController (10s timeout) på 5 API-ruter som gjør eksterne HTTP-kall uten timeout-guard. Dette forhindrer 522-feil i produksjon.

**Arkitektur:** Hver rout får et `AbortController` med 10s timeout som kobles til alle `fetch()`-kall via `signal: controller.signal`. Rydder opp med `clearTimeout()` i finally-blokk.

**Tech Stack:** TypeScript, Next.js API-ruter, Cloudflare Workers

**Forutsetning:** Implementatøren kjenner kodebasen. Hver task står alene — ingen avhengighet mellom tasks.

### Task 3: `webhooks/vipps` — Timeout på Vipps auth + webhook-prossesering

**Objektiv:** Legg til 10s timeout på Vipps access token `fetch()`-kallet i `getVippsAccessToken()`.

**Filer:**
- Modify: `src/app/api/webhooks/vipps/route.ts:15-40` (funksjonen `getVippsAccessToken`)

**Step 1: Legg til timeout-funksjonalitet**

Erstatt `getVippsAccessToken()`:

```typescript
async function getVippsAccessToken(): Promise<string> {
  const clientId = process.env.VIPPS_CLIENT_ID;
  const clientSecret = process.env.VIPPS_CLIENT_SECRET;
  const subscriptionKey = process.env.VIPPS_SUBSCRIPTION_KEY;

  if (!clientId || !clientSecret || !subscriptionKey) {
    throw new Error("Missing Vipps credentials");
  }

  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), 10000);

  try {
    const res = await fetch("https://api.vipps.no/accesstoken/get", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "client_id": clientId,
        "client_secret": clientSecret,
        "Ocp-Apim-Subscription-Key": subscriptionKey,
      },
      signal: controller.signal,
    });

    if (!res.ok) {
      throw new Error(`Vipps auth failed: ${res.status}`);
    }

    return (await res.json()).access_token;
  } finally {
    clearTimeout(timeoutId);
  }
}
```

Merk: `return data.access_token` forenkles til `return (await res.json()).access_token`.

## Risiko

| Risiko | Tiltak |
|--------|--------|
| `AbortController.abort()` kaster `AbortError` | Må fanges i catch og returneres som 504/502 |
| Timeout for kort for Binance API (tregt) | 15s for Binance, 10s for Vipps/Resend |
| Bibliotekfunksjoner har mange kallere | Kun cron-kontekst påvirkes; timeout er trygg |
