## Design-oppsummering

### Hovedvisning (bestemor ser først)

```
┌─────────────────────────────────────┐
│  🤖 ROBOTEN KJØRER          🟢     │
│                                     │
│  Du har tjent:                      │
│  + 47,50 kr i dag                   │
│                                     │
│  [████████████████████]  +2,3%      │
│                                     │
│  Hvorfor? Prisen gikk opp,          │
│  roboten solgte dyrt.               │
│                                     │
│  ┌─────────┐ ┌─────────┐ ┌────────┐│
│  │  🛑     │ │   ℹ️    │ │   ⚙️   ││
│  │ STOPP   │ │  INFO   │ │ INNST. ││
│  └─────────┘ └─────────┘ └────────┘│
└─────────────────────────────────────┘
```

### Nøkkelelementer

| Element | Spesifikasjon |
|---------|-------------|
| **Status** | «Roboten kjører» + trafikklys (🟢) |
| **Gevinst** | Stor, grønn, sentrert |
| **Forklaring** | «Prisen gikk opp, roboten solgte dyrt» |
| **Stopp** | Stor, rød, midt på skjermen |
| **Info** | Popup med enkel forklaring |
| **Innstillinger** | Krever bekreftelse |

### Tekststørrelser

| Element | Størrelse |
|---------|-----------|
| Hovedtall (gevinst) | 48px |
| Status | 24px |
| Forklaring | 20px |
| Knapper | 20px |
