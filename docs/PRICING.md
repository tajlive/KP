> **Versjon:** 3.0.0

---

## 1. Oversikt

Klarpakke bruker en **freemium-modell** med tre nivåer. Prisene er satt for å maksimere konvertering fra gratis til betalt, samtidig som terskelen for oppgradering er lav nok til å fange nybegynnere tidlig.

| Tier | Pris | Nøkkelverdi |
|------|:----:|-------------|
| 🆓 **Gratis** | 0 kr | Risikofri læring — paper trading uten binding |
| ⭐ **Premium** | 199 kr/mnd | Live trading med AI-støtte — ekte markeder |
| 👑 **Professor** | 499 kr/mnd | Copy trading + AI-strategier — maksimal avkastning |

> ⚠️ Klarpakke er en utdanningsplattform. Vi gir ikke finansielle råd. All trading skjer under brukerens eget ansvar.

---

## 2. Gratis (0 kr/mnd)

**For:** Alle nybrukere, nysgjerrige, de som «vil prøve før de kjøper»

| Funksjon | Tilgang |
|----------|:-------:|
| Paper Trading (simulert) | ✅ 3 coins (BTC, ETH, SOL) |
| Basic Analytics | ✅ Kurs, volum, enkel chart |
| Læringsmoduler | ✅ Introduksjonskurs |
| AI-signaler | ❌ |
| Live Trading (Binance) | ❌ |
| Copy Trading | ❌ |
| Leaderboard | ❌ |
| Kundestøtte | ❌ (kun FAQ) |
| Risiko | **0%** — kun fiktive midler |

**Mål:** Onboarding og habit-building. Brukeren skal oppleve mestring og forstå verdien av Premium før vi ber om betaling.

## 3. Premium (199 kr/mnd)

**For:** Aktive paper tradere som er klare for ekte markeder

| Funksjon | Tilgang |
|----------|:-------:|
| Paper Trading (simulert) | ✅ Alle coins |
| Live Trading (Binance) | ✅ Full tilgang |
| AI-drevet innsikt | ✅ Signal-forklaringer, risikoanalyse |
| Leaderboard | ✅ Se rangering, badges |
| Alle læringsmoduler | ✅ Fullt pensum |
| Avanserte charts | ✅ Indikatorer, multi-timeframe |
| Grunnleggende strategier | ✅ DCA, Trend-følging |
| E-postvarsler | ✅ Pris, signaler, posisjoner |
| Kundestøtte | ✅ E-post (24t respons) |
| Risiko | ✅ Stop-loss, take-profit |

**Prisbegrunnelse:** 199 kr/mnd er prisen på en kinobillett + en burger — lav nok til at det føles som en selvfølge for noen som allerede trader aktivt i paper-modus. Samtidig er det høy nok til å signalisere verdi.

## 4. Professor (499 kr/mnd)

**For:** Power users, seriøse tradere, de som vil automatisere

| Funksjon | Tilgang |
|----------|:-------:|
| Alt i Premium | ✅ |
| Copy Trading | ✅ Følg topp-tradere automatisk |
| AI-genererte strategier | ✅ Skreddersydde strategier |
| SmartTrader v3.1 | ✅ Full auto-trading |
| Prioritet kundestøtte | ✅ Chat (2t respons) |
| Tidlig tilgang | ✅ Nye funksjoner før alle andre |
| Egendefinerte varsler | ✅ SMS + Push |
| Avanserte strategier | ✅ Grid, Multi-signal, DCA+ |
| API-tilgang | ✅ WebSocket + REST |
| Ingen annonser | ✅ Helt rent grensesnitt |

**Prisbegrunnelse:** 499 kr/mnd plasserer Professor som et premiumprodukt, men godt under konkurrerende verktøy som 3Commas (~500–1 500 kr/mnd). Forskjellen fra Premium er stor nok til at de fleste brukere vil falle inn under Premium, mens dedikerte tradere ser verdien av Professor.

## 7. Konverteringsstrategi

```
Gratis-bruker ──(3 paper trades)──→ AI-innsikt vist i dashboard
    │
    ├── Oppgrader til Premium for å låse opp:
    │   • Live trading (ekte marked)
    │   • Full coin-tilgang
    │   • Leaderboard (sosialt press)
    │
    └── Oppgrader til Professor for å låse opp:
        • Copy trading (følg profiler)
        • AI-strategier (automatisering)
        • Eksklusiv tidlig tilgang
```

**Konverteringstriggere:**
- Etter 3. vellykket paper trade → popup om Premium
- Når leaderboard viser «kun tilgjengelig for Premium»
- Når brukeren når grensen på 3 gratis coins
- Ukesepost: «Du er topp 10% — lås opp full potensial»

## 8. Churn-forebygging

| Tiltak | Mål |
|--------|-----|
| Onboarding-e-postserie første 7 dager | Redusere churn første måned |
| Månedlig «din fremgang»-rapport | Opprettholde engasjement |
| Gratis nedgradering (behold data) | Hindre fullstendig tap av bruker |
| Henvisningsprogram (1 mnd gratis) | Viral vekst |

---

## 9. Prisjusteringer

- **Nye priser:** Oppdater dette dokumentet + Stripe-produkter
- **Eksisterende kunder:** Grandfatheres i minimum 6 måneder
- **Varsel:** 30 dager før prisendring for alle abonnenter
