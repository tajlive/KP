# Konkurrenter: Hva gjør det spennende for brukere + 50 000 KLT til månedens vinner

**Formål:** Kort oversikt over hva de 10 største konkurrentene gjør for engasjement, og hvordan Klarpakke kan fremheve **50 000 KLT premie til månedens vinner** i samme ånd.

---

## 1. Hva de 10 konkurrentene gjør (design + engasjement)

Basert på `docs/design-konkurranse-analyse-2026.md` og bransjetrender 2024–2025:

| Konkurrent      | Hva som gjør det spennende / engasjerende                                                                                                                                                 |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Binance**     | AI-tilpasset forsiden, Basic vs Advanced-modus, smarte anbefalinger. Lav kognitiv belastning.                                                                                             |
| **Kraken**      | «Bold, lean, fast» – tre-klikk-kjøp, Buy/Sell/Send tydelig. Færre steg = mindre friksjon.                                                                                                 |
| **eToro**       | **Copy trading** og community i sentrum. Velg trader → se statistikker → tildel beløp → Copy. Mikrolæring og fellesskap.                                                                  |
| **Coinbase**    | Enkel første handel, tydelig enkel vs Pro. Tillit (2FA, sikkerhet). Én CTA per skjerm.                                                                                                    |
| **TradingView** | Dashboard med paneler (saldo, posisjoner, PnL, risiko). Tydelig informasjonshierarki og sanntidsdata.                                                                                     |
| **Firi**        | Vipps/BankID onboarding på minutter. Invest vs avansert. Skattekalkulator og sparing. Lokal tillit.                                                                                       |
| **Revolut**     | Handel fra £1. **Stories-aktig mikrolæring** – brukere som tar korte leksjoner handler mer. Balanse tydelig på forsiden.                                                                  |
| **Bybit**       | **Demo tydelig atskilt fra live** (egen bruker/domene). **WSOT (World Series of Trading)** – 2025: 71 765 aktive tradere på én dag, $10M USDT premiepool, 520 000 deltakere fra 202 land. |
| **Crypto.com**  | Widget-basert, tilpassbar UI. «Trending», nye tokens, personlig Earn. Discovery og belønninger.                                                                                           |
| **Wise**        | Én primær handling per skjerm. Transparente gebyrer. Full åpenhet = tillit.                                                                                                               |

## 2. Bransjetrender: Hva gjør det spennende for brukere (2024–2025)

- **Leaderboards og prestasjoner** – konkurranse, ranking, synlig fremgang.
- **Tokeniserte belønninger** – cashback, Bitcoin, native tokens; korte feedback-looper.
- **Daglige / ukentlige / sesongbaserte konkurranser** – faste «events» brukere kan forberede seg på.
- **Læringsmisjoner** – kombinasjon læring + belønning (Revolut Stories, eToro community).
- **Sosiale elementer** – utfordre venner, felles oppdrag (eToro copy, Bybit WSOT).
- **Tydelig skille paper vs live** – trygg øving før ekte penger (Robinhood demo før registrering, Bybit demo-konto).

**Effekt:** Gamified plattformer har typisk **30–50 % høyere brukerretensjon** gjennom poeng, leaderboards og klare milepæler.

## 3. Klarpakke: 50 000 KLT til månedens vinner

**Eksisterende:** KLT Token System beskriver månedlig trading-konkurranse (inngang 1 000 KLT), KLT-premier og læringsbelønninger. En **50 000 KLT premie til månedens vinner** passer perfekt inn og skiller dere fra mange konkurrenter som kun har «rabattkoder» eller diffuse belønninger.

### Anbefalinger for å gjøre premien spennende og synlig

1. **Faste, forutsigbare events**
   - Tydelig «Månedens konkurranse» med start/slutt (f.eks. 1.– siste dag i måneden).
   - Countdown eller «X dager igjen» på dashboard / paper-trading / egen konkurranseside.

2. **Synlig premie og regler**
   - Én setning som alltid er lett å finne: **«50 000 KLT til månedens vinner»** (landing, priser, dashboard, konkurranseside).
   - Korte regler: hva teller (f.eks. paper PnL, risikojustert avkastning), hvem som kan vinne, når vinneren kåres.

3. **Leaderboard som driver engasjement**
   - Månedlig leaderboard der brukere ser sin plassering og avstand til topp (som Bybit WSOT, men med KLT-premie).
   - Ev. «Du er #X denne måneden» på dashboard eller i KLTWallet.

4. **Kombiner med læring**
   - «Månedens vinner» basert på risikojustert resultat eller fullførte kurs + paper-resultat, slik at premien styrker både læring og øving (Revolut/eToro-ånd).

5. **Kort kommunikasjon**
   - Landing / priser: «Tjen KLT gjennom kurs og konkurranser – 50 000 KLT til månedens vinner.»
   - E-post / push når konkurransen starter og når det er X dager igjen.
   - Ev. liten banner på paper-trading: «Månedens konkurranse pågår – 50 000 KLT til vinneren.»

6. **Tillit og åpenhet**
   - Kåring og vinner kunngjort (anonymisert eller med samtykke). Korte, tydelige kriterier (Wise-ånd: ingen skjulte regler).

## 4. Oppsummert

| Konkurrentene gjør                                    | Klarpakke med 50k KLT-premie                                                                     |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Leaderboards og konkurranser (Bybit WSOT, Crypto.com) | Månedlig leaderboard + **50 000 KLT til månedens vinner** tydelig og fast.                       |
| Tokeniserte belønninger                               | KLT for læring, streak, quiz + stor månedlig premie.                                             |
| Læring + belønning (Revolut, eToro)                   | Kurs, quiz, paper trading som teller mot konkurransen.                                           |
| Tydelig paper vs live                                 | Behold tydelig skille; månedens vinner kan baseres på paper (eller definert risikojustert live). |
| Faste events                                          | Én konkurranse per måned med klar start/slutt og countdown.                                      |

**Én setning å gjenbruke:** _«50 000 KLT premie til månedens vinner – konkurrer på leaderboardet med paper trading og læring.»_
