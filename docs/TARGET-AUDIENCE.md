## Primærpersona: småsparere

| Dimensjon     | Beskrivelse                                                                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Økonomisk** | Småsparere — begrensede beløp, behov for oversikt og trygghet fremfor «max gain».                                                                                         |
| **IT**        | Middels digital kompetanse: bruker mobilbank, nettbutikk og apper daglig, men ikke utvikler/admin.                                                                        |
| **Krypto**    | Lav til ingen forkunnskap — trenger forklaring av begreper før forkortelser og «pro»-språk.                                                                               |
| **Enhet**     | **Ca. 70–75 % av bruk på mobil**; **design- og testantagelse: telefoner nyere enn 2023-modell** (moderne skjermer, 4G/5G, god ytelse — likevel ikke tunge første laster). |

## Konsekvenser for teamet

- **Én primær handling per skjerm** der det er mulig; unngå parallelle «pro»-konsepter uten forklaring.
- **Paper før live** kommuniseres tydelig; risiko og gebyr i enkelt språk der det trengs.
- **Hjelp og akademi** lenkes der brukeren kan stå fast (feilmeldinger med «neste steg»).
- **i18n:** `no` og `en` prioriteres i copy-kvalitet; `th` / `zh` holdes i paritet der ressurser tillater (se roadmap).
