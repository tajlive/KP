# 🚀 START HERE: Quick Webflow Integration (45 min)

## 3-Step Deployment

### Step 1: Add CSS (5 min)
```html
Webflow: Project Settings → Custom Code → HEAD

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/tombomann/klarpakke@main/web/styles/coinbase.css">
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500;600&display=swap" rel="stylesheet">
```

### Step 2: Apply Templates (20-30 min)
```
For each of 18 pages:
1. Copy HTML from: docs/WEBFLOW-ALL-PAGES-TEMPLATES.md
2. Paste into Webflow page
3. Preview (Cmd+P)
4. Move to next page
```

### Step 3: Test & Publish (10-15 min)
```
1. Test all pages (responsive, colors, no errors)
2. Publish → Staging domain
3. Test live at: klarpakke.webflow.io
```
