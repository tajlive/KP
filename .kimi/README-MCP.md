# MCP-konfig for KIMI CLI

**`mcp-config.json` er en synkronisert kopi av `.cursor/mcp.json` — rediger aldri direkte, endre alltid master.**

## Synkronisering

```bash
npm run mcp:sync        # Kopier master til alle kopier
npm run mcp:validate-config   # Verifiser at alle er i sync
```
