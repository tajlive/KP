## STEG 2 — Fix checkSonarHealth test (P0 blokkerer prod)

Filen: src/lib/ai/sonar/__tests__/client.test.ts

Rotårsak: `checkSonarHealth()` returnerer healthy:false fordi PERPLEXITY_API_KEY
ikke er satt i testmiljøet. Testen mangler `beforeEach` med mock av env-variabel.

Fix: Legg til `process.env.PERPLEXITY_API_KEY` mock i `describe('checkSonarHealth')` blokken.

Erstatt denne koden:
```typescript
describe('checkSonarHealth', () => {
  it('should return healthy when configured', async () => {
    const result = await checkSonarHealth();
    expect(result.healthy).toBe(true);
  });
});
```

Med denne:
```typescript
describe('checkSonarHealth', () => {
  beforeEach(() => {
    process.env.PERPLEXITY_API_KEY = 'test-api-key-for-health-check';
  });

  afterEach(() => {
    delete process.env.PERPLEXITY_API_KEY;
  });

  it('should return healthy when configured', async () => {
    const result = await checkSonarHealth();
    expect(result.healthy).toBe(true);
  });

  it('should return unhealthy when not configured', async () => {
    delete process.env.PERPLEXITY_API_KEY;
    const result = await checkSonarHealth();
    expect(result.healthy).toBe(false);
  });
});
```

Validering etter fix:

Forventet: alle 12 tester (eller flere) passerer.
