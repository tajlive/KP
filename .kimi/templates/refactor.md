# Refactor Template

## Prompt
```
Refaktorer [KODE] i /Users/taj/klarpakke.

## Steg
1. Les eksisterende kode (kimi_read)
2. Analyser forbedringspotensial (kimi_large)
3. Planlegg endring (kimi_medium)
4. Implementer gradvis (kimi_refactor)
5. Test etter hver endring (kimi_test)
6. Verifiser ingen funksjonell endring

## Regler
- Aldri endre oppførsel, kun struktur
- behold alle tester grønne
- Dokumenter hvorfor refaktorering var nødvendig

## Output Format
A) Status: GO/NO-GO
B) Før: [tilstand]
C) Etter: [forbedring]
D) Risiko: [lav/medium/høy]
E) Test-dekning: [status]
```

## Eksempel
```
Refaktorer src/lib/trading/ til å bruke strategi-pattern i /Users/taj/klarpakke.
```
