# [Frontend] fix(trading): resolve grid bot crash caused by hardcoded maxDailyTrades=10

Root cause: maxDailyTrades was hardcoded to 10 in multiple places:
- paper/route.ts auto_trade_settings upsert
- cron/tick/route.ts DEFAULTS and riskConfigMap
- lib/supabase/auto-trading.ts create path
- Grid strategy had no persistent boundaries, causing repeated signals

Fixes:
- Store full risk_config in strategy_config on bot creation
- Read daily_trade_limit from auto_trade_settings in tick engine
- Apply grid-level multiplier for grid strategy (levels*2 min trades)
- Make grid boundaries persistent instead of recalculating every tick
- Fix createRiskManager to support low/medium/high mapping
- Derive auto_trade_settings defaults from optimized risk profiles

Also archived 15 crashed sessions and created DCA fallback bot.
