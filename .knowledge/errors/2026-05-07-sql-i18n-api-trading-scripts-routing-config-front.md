was set. Most trade insertion paths didn't set realized_pnl.

   open_position entry_price when not provided.
2. trading-api.ts getPortfolio/getActiveStrategies: compute P&L from
   current_capital_nok - starting_capital_nok.
3. usePulseData.ts: compute P&L from capital diff.
4. bot-store.ts: compute pnlNok/pnlPct from capital diff.
5. trading/balance.ts: compute sessionPnl from capital diff.
6. All user-facing pages (portfolio, paper-trading, auto-trading,
   PortfolioDashboard) and API routes now compute P&L consistently.
7. Admin sessions API returns computed total_pnl.

This ensures ALL pages show identical P&L numbers regardless of which
code path fetches the data.
