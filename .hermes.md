## CI/CD Pipeline (ny — 2026-07-15)

1. Push til `main` → GitHub Actions `auto-deploy.yml` trigger
2. **check-secrets** jobb: verifiserer GitHub Secrets finnes
3. **deploy** jobb: self-hosted runner (Mac/PC) bygger med `cf:build`
4. Bygget har `NEXT_PUBLIC_SUPABASE_URL` og `NEXT_PUBLIC_SUPABASE_ANON_KEY` fra Secrets
5. `wrangler deploy` laster opp til Cloudflare Workers
6. **Post-deploy verify:** helse + sider + 0 Supabase-feil

### Manuell deploy
```bash
npm run deploy          # Bygg pa PC → deploy
npm run deploy:mac      # Bygg pa Mac → deploy
npm run deploy -- --check-secrets   # Bare sjekk secrets
```
