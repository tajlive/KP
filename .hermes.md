## Viktige arkitekturbeslutninger

1. **Client-side auth** — `requireAuth()` feiler på Cloudflare Workers (SSR). All auth skjer via `AuthProvider` / `useAuth()`.
2. **i18n konsolidert** — alle nøkler i `messages/no.json` / `en.json`. Split-filer fungerer ikke i Worker.
3. **Balance source of truth** — `paper_accounts.current_balance`. DB trigger syncer til `user_profiles.paper_balance`.
4. **Binance 403** — Cloudflare Workers IP er blokkert. Bruk Supabase Edge Function `binance-proxy` for å omgå.
5. **Price cache** — 10s in-memory TTL i BinanceMarketDataProvider. Vedlikeholdes av `sync-prices` cron.
6. **Slippage** — 0.2% (realistisk for paper trading).
