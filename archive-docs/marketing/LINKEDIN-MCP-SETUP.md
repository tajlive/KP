# 🤖 LinkedIn MCP Server for Klarpakke

> **Full LinkedIn-automasjon via Model Context Protocol (MCP)**

---

## 🎯 What You Get

- ✅ **Profile Analytics** - Track network growth & engagement
- ✅ **Content Automation** - Create & schedule posts
- ✅ **Lead Generation** - Search & connect with prospects  
- ✅ **Competitor Analysis** - Monitor competitor strategies
- ✅ **Content Calendar** - Auto-generate weekly schedules

---

## 🚀 Quick Start (30 seconds)

```bash
# 1. Build MCP server
cd mcp-server && npm install && npm run build

# 2. Setup Claude Desktop
bash scripts/mcp/setup-claude-desktop.sh

# 3. Restart Claude Desktop - done!
```

## 💬 Example Commands

| What You Say | What Happens |
|--------------|--------------|
| "Generate 5 LinkedIn posts about trading" | Gets 5 content ideas with hooks |
| "My network stats last 30 days" | Shows growth, impressions, engagement |
| "Find risk managers in Norway" | Returns 10 matching profiles |
| "Weekly calendar for fintech" | Creates 3-post weekly schedule |
| "Analyze competitor linkedin.com/in/john" | Strategy analysis report |

## 🛠️ Available Tools

### Profile & Network
- `linkedin_get_profile` - Get profile info
- `linkedin_get_network_stats` - Network analytics
- `linkedin_search_people` - Prospect search
- `linkedin_send_connection_request` - Send invites

### Content
- `linkedin_create_post` - Create/schedule posts
- `linkedin_get_post_analytics` - Post performance
- `linkedin_generate_content_ideas` - AI content ideas
- `linkedin_schedule_content_calendar` - Weekly planner

### Intelligence
- `linkedin_get_company_updates` - Company monitoring
- `linkedin_analyze_competitor` - Competitor analysis
