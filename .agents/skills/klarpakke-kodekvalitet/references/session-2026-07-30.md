# Code Quality Session: 2026-07-30 — JokerTrade deduplisering

## Task

Fjern duplisert `calculateRSI` fra `src/app/api/jokertrade/route.ts` og bruk den kanoniske fra `src/lib/trading/indicators.ts`.

## Filene som ble endret

| Fil | Endring |
|-----|---------|
| `src/app/api/jokertrade/route.ts` | La til import, slettet lokal `calculateRSI` (16 linjer), oppdaterte kall på linje 69 |
| `src/app/api/jokertrade/__tests__/route.test.ts` | Slettet lokal duplikat (26 linjer), la til import fra kanonisk, oppdaterte 4 test-assertions |

## Signatur-forskjell

| Aspekt | Lokal (slettet) | Kanonisk (`indicators.ts`) |
|--------|-----------------|---------------------------|
| Returtype | `number` | `(number \| null)[]` |
| Algorithme | Enkel sum av siste `period` gevinster/tap | Wilder's smoothed (EMA-inspirert) |
| Edge: alle opp | Returnerer `100` | Returnerer `99.0099` (rs=100 → 100-100/101) |
| Edge: alle ned | Returnerer `0` | Returnerer `~0.41` (rs=0.0041 → 100-100/1.0041) |
| Default period | Obligatorisk | `= 14` |

## Test-assertions før/etter

```typescript
// FØR (lokal funksjon, single number)
expect(calculateRSI([100], 14)).toBe(50);
expect(calculateRSI(prices, 14)).toBe(100);       // <- feiler med kanonisk

// ETTER (kanonisk, array)
const rsi = calculateRSI(prices, 14);
expect(rsi.every((v: number | null) => v === null)).toBe(true);  // insufficient data
expect(rsi[rsi.length - 1]).toBeCloseTo(99, 0);                  // all up → ~99
expect(rsi[rsi.length - 1]).toBeCloseTo(0, 0);                   // all down → ~0
expect(rsi[rsi.length - 1]).toBeGreaterThan(40);                 // sideways → ~50
```

## Fallgruve oppdaget

`npx tsc --noEmit` ga 0 feil SELV om testene fortsatt refererte til den slettede `calculateRSI` — fordi `tsconfig.json` ekskluderer `**/*.test.ts`. Testene feilet først ved `npx vitest run`. ALLTID kjør tester separat etter deduplisering.
